## Что делает (2–3 предложения)
Набор из 9 плагинов для Teleton-агента (Telegram AI-агент @morgan_agent) по рынку Telegram Gifts на TON: whale-analytics, chart (QuickChart.io + sharp), giftstat, gift-price-compare, marketapp, getgems, dyor, geckoterminal, invoices. README заявляет, что торговые инструменты marketapp и getgems подписывают транзакции кошельком агента и что 6 плагинов работают без API-ключей. Заявления README ("10 200+ строк", "50+ инструментов") не проверены.
