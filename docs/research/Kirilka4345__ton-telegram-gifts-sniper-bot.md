## Что делает (по README)
Бесплатная часть, по словам README, отслеживает флоры коллекций Telegram-подарков, сортирует их по спреду `floor_ton` и `next_ton` (разница между самым дешёвым и следующим листингом) и генерирует HTML-страницу `TON_GIFTS_SNIPER.html`. Заявлено «Zero API key required for public floor scanning». Автопокупка («Pro Auto-Buy Module: WebSockets + Instant Wallet v5r1 Execution + Portals TMA Sniper») продаётся отдельно за 15 TON / $25.
