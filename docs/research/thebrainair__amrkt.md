## Что делает

Асинхронная Python-библиотека для маркета MRKT: поиск листингов, покупка, выставление, инвентарь, возврат в Telegram, баланс. Авторизация через сессию Telegram (api_id/api_hash), токен обновляется автоматически.

## Как устроено (всё из README, не проверено по коду)

- Источник данных: эндпоинты на странице не названы (их даёт boostNT/MRKT-API, см. отдельный отчёт). Есть `search_gifts()`; курсорная пагинация в примере: параметры `cursor` и `count=50`, цикл заканчивается, когда `cursor` пустой или элементов меньше `count`. Ограничение `count` ≤ 20 из задания D на странице НЕ подтверждено («максимальное значение count: нет на странице»), а в boostNT/MRKT-API для `gifts/saling` указан максимум 20 — расхождение с примером `count=50`, надо проверить на практике.
- Авторизация: нужны `api_id`/`api_hash` с my.telegram.org; сессия хранится в файле (`session_name`, `workdir`). Токен обновляется автоматически. Срок жизни токена: нет на странице.
- Методы (сигнатуры из README):
  - `buy_gifts(gift_ids)` → `List[PurchaseResult]`
  - `sell_gifts(gift_ids, prices)` → `SaleResult`; цены в nanoTON (10 TON = 10_000_000_000)
  - `get_inventory(...)` → `GiftList` (те же параметры, что у `search_gifts()`)
  - `return_gifts(gift_ids)` → `bool` (возврат подарков в Telegram)
  - `get_balance()` → `Balance` с полями `soft`, `hard`, `stars` и хелперами в TON (`soft_ton`, `hard_ton`, `total_hard_ton`)
- Заголовки и защита: по умолчанию браузерные заголовки, Cookie, имитация TLS (`impersonate`, значения `chrome99`–`chrome124`, `safari15_3`, `safari17_4_1`; пустая строка отключает), случайный User-Agent с ротацией (`user_agent`). Полный список заголовков: нет на странице.
- Прокси: параметр `proxy` (`http://` или `socks5://`, с логином/паролем); используется и для API, и для входа в Telegram; при 407 от HTTP-прокси есть `proxy_api_only=True`.
- Лимиты запросов: нет на странице. В модели `UserInfo` есть поле `disable_withdrawal_limit` (лимит вывода не описан).
- Модель данных подарка, флор, комиссии, предохранители, история продаж, офферы, WebSocket: нет на странице.
