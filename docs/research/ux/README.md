## 2. xGift

Единственный найденный подробный источник — статья на dev.to, помеченная как партнёрская (все ссылки ведут на редирект `ton-adoption.xyz/go/?to=xgift`, автор сам указывает партнёрскую программу). Тон рекламный; **все цифры — заявлено, не проверено.**

- Источники:
  - https://dev.to/ton-adoption/xgift-complete-review-upgraded-telegram-gifts-marketplace-2026-5hhm
  - https://dev.to/ton-adoption/xgift-vs-portals-vs-tonnel-vs-mrkt-gifts-marketplaces-2026-48cj
  - первоисточник статьи: https://ton-adoption.xyz/en/blog/xgift-complete-review-upgraded-gifts-marketplace-2026/
- Ссылки (по статье): бот `@xgift` / `t.me/xgift_bot` (в статье встречаются оба написания — нужно сверить вручную); Premium `@xgift_premium`; упомянуты фишинговые клоны `@xgift_real_bot`, `@x-gift_bot`. Канал: **не найдено.**
- Формат: Telegram Mini App + бот; вход через TON Connect; эскроу-контракт; фикс-цена и аукционы (24–72 ч, минимальный шаг 5%).
- Аналитика (заявлено): флор в TON, распределение редкости (символ × фон × узор), топ продаж за 30 дней, премия за трейты, анализ холдеров, лидерборд флипперов (вторая статья).
- Фильтры (заявлено): символ, фон, цена, дата минта; сортировка по флору / новизне / редкости; в Premium — фильтры по трейтам с сохранёнными поисками.
- Уведомления (заявлено, только Premium): пуши о новых листингах ниже флора («sub-floor alerts»), алерты о всплеске объёма (в примере >50% за 24 ч); продавцу — уведомление о продаже. Как именно выглядит сообщение, кнопки, задержки: **не найдено.**
- Комиссии (заявлено, не проверено): покупка 5% (3% с Premium); листинг 0%; отмена листинга ~0,05 TON газ; аукцион 5% с финальной цены; Premium 2–3 TON/мес; газ ~0,05 TON за транзакцию. Для сравнения автор приводит: Portals 5%, Tonnel 3–5%, MRKT 2%. Замечание: утверждение статьи о «окупаемости Premium от ~40 TON объёма» арифметически не сходится (экономия 2% с 40 TON ≈ 0,8 TON < 2–3 TON) — доверять цифрам нельзя.
- Скриншоты: в статье интерфейсных скриншотов нет; есть только обложка (рекламная): https://ton-adoption.xyz/og/blog/en-xgift-complete-review-upgraded-gifts-marketplace-2026.png

Для Gift Flipper: xGift — по описанию, скорее маркет/аналитика, а не снайпер; идея «sub-floor alert как платная функция» и «сохранённые поиски по трейтам» совпадает с нашими пресетами.
