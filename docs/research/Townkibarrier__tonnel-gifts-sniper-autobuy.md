## Что делает (2–3 предложения)

По README: self-hosted снайпер подарков на Tonnel. Учитывает 10% комиссию покупки поверх цены, фильтрует ловушки (другая валюта, бандлы, аукционы, `export_at`), строит кластерный флор с доверием, сверяется с оценкой Telegram, Portals/MRKT и (опционально) с ресейл-маркетом Telegram. По умолчанию — практика, живой режим на 24 ч.

## Как устроено (по README, не проверено)

- **Источник данных:** polling каждые 2 с; правила группируются по фильтру; на группу — «новые» и «дешёвые» через `pageGifts` (публичный, без `initData`). Флоры `filterStats` (нужен `initData`) кэшируются на `FLOOR_CACHE_TTL` (60 с). Бандлы, аукционы и листинги без цены отбрасываются на входе. Бэкофф на 429, **Cloudflare 403** и сетевые ошибки; уведомление после 5 ошибок; предупреждение, если нет успешного цикла `STALE_DATA_SEC`.
- **Авторизация:** Telethon открывает Mini App @Tonnel_Network_bot (short name `gifts` — не подтверждено; запасной `RequestWebView` с `TONNEL_WEBAPP_URL`) → `initData`. Вручную: `market.tonnel.network` → DevTools → Local Storage → `web-initData`. Автор прямо пишет: `initData` Tonnel даёт **полный доступ к аккаунту Tonnel, включая вывод**.
- **Модель данных:** `gift_id`, цена (без 10% комиссии), коллекция с суффиксом редкости вида `(1.5%)`, модель, фон, символ, `export_at`, актив (TON / USDT — `TONNEL_ASSET`), признаки бандла/аукциона; `pageGifts` не отдаёт время листинга.
- **Покупка:** `buyGift` с сырой ценой листинга (сервер предположительно добавляет 10%); поле `wtf` — CryptoJS-пароль из `tonnelmp` 1.2 («константа фронтенда, может смениться»). Покупка уходит на `gifts.coffin.meme`, поиск — `gifts2.tonnel.network`. Успех — только `{"status":"success"}`; явный отказ — `{"status":"error"}`, HTTP 4xx, rate limit, auth error; всё остальное — `unknown`.
- **Хранение:** SQLite (+ `kv`, `shadow_fills`), `data/events.jsonl`, файлы `data/floors_tonnel.json` и (с `TG_MARKET`) `data/floors_telegram.json`; `data/run.lock` — один процесс на каталог данных.

## Идеи по пунктам задания I (только идеи)

### 1. Кластерный флор, доверие, запасной вариант
- Кластер: самая низкая цена с ≥2 другими в пределах +10% выше; `high/med/low` по числу сопоставимых; без кластера ≥3 — всегда `low`, две приманки не пройдут дефолтный `min_confidence=med`; скачок >25%/ч понижает уровень.
- Запасной вариант: **собственные флоры Tonnel** (`filterStats`, по ключу «коллекция_модель (редкость)»).
- Ловушки до любых расчётов: листинг в другом активе (USDT), бандлы, аукционы, нет единицы цены; будущий `export_at` = блокировка (`EXPORT_AT_LOCKS=true`). Автор предупреждает: 20 из 43 листингов Toy Bear 2026-10-28 имели `export_at` до 2 недель вперёд — с дефолтом большая часть рынка не покупается. Цена <25% флора — только карточка.
- Мотивация (цитата автора): публичный paper-trading 639 перепродаж (ссылка на ufosog/gift-sniper, не открывалась) дал медиану **−2.0%**, прибыльны лишь 10% сделок — то есть «скидка к флору ≠ прибыль».

### 2. Оценка Telegram (`payments.getUniqueStarGiftValueInfo`)
- average, last sale, listed count; выше средней **или** последней продажи на тонком флоре → спросить (в Portals/MRKT-версиях — «и», здесь — «или»: формулировки расходятся).
- Дополнительно: ресейл-маркет самого Telegram через сессию (`TG_MARKET`) как опорная цена — поля `StarGift.title`, `StarGiftUnique.resell_amount`, единица цены TON неясна (по TL-схеме nanoTON, по «другим заметкам» 1/100 TON), комиссия ресейла предполагается 20%. Путь не запускался.
- Сверка с документацией MTProto выполнена на Этапе 0 отдельно (п. 0.4 плана): поля и ограничения — в `docs/research/SUMMARY.md` §3 (источник: core.telegram.org через результаты поиска и зеркала схемы). В этом отчёте поля не перечисляются, чтобы не дублировать непроверенный пересказ.

### 3. Предохранители
- `DRY_RUN=true` — жёсткий замок; повторный `DRY_RUN=true` отменяет открытое окно и неиспользованную кнопку go-live. Live = `DRY_RUN=false` + `/dry off`; окно `LIVE_ARM_HOURS=24`; «неправдоподобное» окно (дальше 24 ч) = практика.
- Лимиты на all-in **с 10% комиссией**: `MAX_PRICE_TON=20`, `DAILY_BUDGET_TON=50` **на UTC-сутки** (не скользящие), `MAX_BUYS_PER_HOUR=3`, `CONFIRM_ABOVE_TON`. `/preset` только ужесточает.
- Брейкеры: обвал флора, серия убытков (аннулирует кнопку go-live), расхождение баланса, серия ошибок; живая покупка не уходит, если баланс не читается или меньше стоимости.
- `/panic` хранится в БД (переживает рестарт); снятие `/resume` + новый `/dry off`. Все кнопки, меняющие состояние, несут время отправки и сроки (90 с для Buy, 10 мин для Apply/Confirm/Resume, 24 ч для hindsight); старая кнопка не может отменить более новый `/panic` или брейкер.
- **«Результат неизвестен»:** запись `unknown` до запроса; 5xx, таймауты, прочее — `unknown`, считается в лимитах. При выключении новая покупка не стартует, текущая дожидается ответа и записи.
- **Один процесс на каталог данных** (`data/run.lock`): второй `run` или `once` отказывается стартовать — защита от трат вне лока и двух клиентов на одной сессии. (Автор оговаривается «Windows has no such lock» — противоречит «Windows-only»-сборке.)
- Строгая валидация `rules.json`: неизвестный ключ, дубль ключа, отрицательный/нечисловой лимит → ошибка, «опечатка не может ослабить правило».

### 4. Режимы и «дешевле на другом маркете»
- `auto/confirm/watch`; `auto` спрашивает при «слишком хорошо», блокировке, **дешевле на другом маркете** (Portals, MRKT, Telegram), цене выше оценки Telegram на тонком флоре, стоимости > `CONFIRM_ABOVE_TON`. Бюджет второго мнения 3 с.
- Источники: файлы `PEER_FLOOR_FILES`, публичный эндпоинт Portals (`PEER_PORTALS_PUBLIC`), ресейл Telegram (`TG_MARKET`).
- Перепроверка листинга перед тапом (через поиск `{gift_id, price exists, no buyer}`).

### 5. `/doctor`
Конфиг, Telegram-сессия, 2FA, права сессии, авторизация Tonnel, доступность, часы, БД, комиссии, лимиты; подсказка на каждую ошибку; exit code 1. Пока `run` работает, CLI-`doctor` не открывает Telegram-сессию (проверки сессии — через `/doctor` в боте).

### 6. Комиссии — **заявлено, не проверено**
- Tonnel: покупка **+10% поверх цены листинга** (цена в API без комиссии), продажа **0%**, вывод **0 TON**. `FEES_VERIFIED=false`.
- Portals (для пиров): 0% / 5% / 0.1 TON.
- Ресейл Telegram: 20% (предположение).
