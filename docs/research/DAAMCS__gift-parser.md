## Что делает (по README)
Telegram-бот: пользователь присылает список публичных чатов, бот перебирает участников и ищет у них подарки (NFT) с заданными ID, затем выводит информацию о пользователе и его подарках. По README, ботам эта информация недоступна, поэтому нужна пользовательская сессия. К флипу на маркетах отношения не имеет.

## Как устроено (по README)
- Источник данных: участники указанных чатов и их подарки через пользовательскую сессию Telegram. Методы MTProto в README не названы.
- Авторизация: в `config.py` задаются `BOT_TOKEN`, `ADMINS`, `API_ID`, `API_HASH`. При первом запуске запрашиваются номер телефона, код и пароль 2FA, сессия «сохранится автоматически» (README, шаги 3–4). Куда сохраняется сессия, не сказано.
- Модель подарка, флор, комиссии, покупка/продажа: не описаны.
