## Что делает

Описывает два эндпоинта MRKT: получение подарков на продаже и получение токена по `initData`.

## Как устроено (из README, не проверено на практике)

**1. Подарки на продаже** — `POST https://api.tgmrkt.io/api/v1/gifts/saling`
- Тело (JSON): `collectionNames`, `modelNames`, `backdropNames`, `symbolNames` — списки (пустой список = без фильтра); `ordering`: `Price`, `ModelRarity`, `BackgroundRarity`, `SymbolRarity` или `None` (по времени выставления); `lowToHigh` (bool); `maxPrice`, `minPrice`, `mintable`, `number` (по умолчанию `None`); `count`; `cursor` (пустая строка для первой страницы); `query`, `promotedFirst` — назначение автор указывает как «неизвестно».
- Ответ: ключи `gifts` и `cursor`. Схема объекта подарка в README не описана.
- Пагинация: курсорная; следующий запрос берёт `cursor` из ответа; если подарков меньше `count`, `cursor` может быть `None`.
- Лимит: `count` максимум 20. Ограничений частоты запросов в README нет.
- Формат цен: НЕ описан (только поля `minPrice`/`maxPrice` без единиц). Единица nanoTON известна из amrkt (см. отчёт), для фильтров не подтверждена.

**2. Токен** — `POST https://api.tgmrkt.io/api/v1/auth`
- Тело: `{"data": init_data}`; `init_data` получается только при запуске мини-приложения в Telegram (Pyrogram в примерах, Telethon упомянут). Токен — в ключе `token` ответа.
- Использование: заголовок `Authorization` (токен); в примере также `Referer: https://cdn.tgmrkt.io/`.
- Альтернатива: скопировать токен из ответа `/auth` во вкладке Network веб-версии Telegram.
- Срок токена: по словам автора неизвестен, но «точно более суток».

Покупка, листинг, баланс, история продаж, офферы, WebSocket: в README НЕТ.

## Сверка с другими источниками

- Совпадает с заданием D (base URL `api.tgmrkt.io`, `/api/v1/auth` с `{"data": initData}`, `gifts/saling`, `count` ≤ 20).
- Сторонний пакет `mrkts` на PyPI (асинхронный клиент, не читался глубже страницы PyPI) перечисляет методы `market.gifts`: `collections`, `models`, `backdrops`, `saling`, `inventory`, `history`, `feed`, `buy`, `sale`, а также `market.offers.activities` и заказы; базовый URL там `https://api.tgmrkt.io/api/v1/`. Значит, `feed` и `history` существуют, но их пути и тела здесь не описаны.
- amrkt: пример пагинации с `count=50` расходится с лимитом 20 здесь (проверить).
