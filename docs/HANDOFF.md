## 2. Что нужно знать за 5 минут

- Правила: `AGENTS.md` §4 — абсолютные. `DRY_RUN=true` всегда. Реальные покупки, листинг, вывод не выполнять и не включать. Эндпоинты покупки — только через `execution.spend()` и только после явного разрешения владельца.
- Чужой код не запускать, зависимости из чужих репо не ставить. Исключения на **перенос фрагментов** с указанием источника: aportalsmp (D-013), topcvetok (D-015). Разделы I и J (`REPO_ANALYSIS.md`) — малварь-приманки, только README.
- Секреты (Telethon-сессия, `api_hash`, initData, токены, токен бота) — только `.env` и `data/` с правами 600. Не коммитить, не логировать, не отправлять наружу.
- Каждый факт про API помечать: «из кода», «из README», «проверено на живом ответе». Не выдумывать; если данных нет — спросить владельца.
- Комиссии не проверены (D-009): `verified=false` → прибыль только «оценка», режимы confirm/auto не включаются.
- Деньги — nanoTON `int`; время — UTC с tz; табличные тесты оценки и комиссий с конкретными числами.
- Перед коммитом: `ruff check`, `ruff format --check`, `pytest` (в `backend/`), `npm run build` (в `webapp/`).
- Владелец пишет по-русски — отвечать по-русски, кратко: сделано / риски / вопросы / что нужно от владельца.

## 3. Шаг для агента на ПК: запись живых фикстур (Этап 2)

Почему на ПК: Telethon-сессия владельца не должна попадать в облачный контейнер (D-016).

Порядок:
1. Убедиться, что `.env` заполнен (`TG_API_ID`, `TG_API_HASH`, путь к сессии в `data/`, права 600). Значения не печатать.
2. Показать владельцу **полный список запросов** (метод, URL, тело без секретов), которые будут отправлены. Только чтение. Бюджет D-008: ≤1 запрос/с на маркет, листинги — не чаще раза в 5 с. Ждать «разрешаю».
3. Запустить скрипт записи фикстур (см. `backend/` и `docs/PLAN.md` п. 2.8 — путь и команда будут там). Скрипт маскирует `initData`, токены и id пользователя перед сохранением.
4. Сравнить живые ответы с фикстурами `"_source": "code:…"`; расхождения — в `MARKETS.md` (пометка «проверено на живом ответе» или «устарело»), поправить парсеры и тесты.
5. Открытые вопросы, которые закрывает этот шаг (`SUMMARY.md` §5): бот и `short_name` Mini App Tonnel (владелец может подсказать), срок жизни токенов, `count`/`limit` максимумы, soft/hard баланс MRKT (только `GET /balance`), актуальность путей tonnelmp, заголовки `x-ratelimit-*` Portals.

Запрещено на этом шаге: `buy`, `sale`, `bulk-list`, `list`, `withdraw`, `offers` (POST/PATCH), `listForSale`, `cancelSale`, `buyGift`, `gifts/buy`, `gifts/sale*`, `return*`, `transactions/{id}`.
