# CLAUDE.md

Все общие правила проекта — в @AGENTS.md. Прочитай его целиком перед любой задачей.

## Дополнительно для Claude Code

- Начинай сессию с `docs/HANDOFF.md`, затем `docs/PLAN.md`: найди первую незакрытую задачу текущего этапа или ту, что назвал пользователь.
- Для разбора чужих репозиториев используй задания из `docs/REPO_ANALYSIS.md`. Разбирай **только чтением** (WebFetch / `gh api` / просмотр файлов). Не клонируй и не запускай код из списка «подозрительные».
- Большие исследования можно отдавать субагентам: один субагент = один репозиторий, результат — файл `docs/research/<owner>__<repo>.md` по шаблону из `docs/REPO_ANALYSIS.md`.
- Перед изменением `execution/` или `pricing/` — сначала напиши/обнови тесты, потом код.
- Никогда не ставь `DRY_RUN=false` и не вызывай эндпоинты покупки/вывода сам.
- В конце задачи: обнови документацию по таблице из AGENTS.md §6, затем кратко отчитайся пользователю: что сделано, что дальше.
- Пользователь пишет по-русски — отвечай по-русски.
